# Changelog

All notable changes to silva-mentis. Version numbers follow
[Semantic Versioning](https://semver.org): bug fixes raise the last number, new features the
middle one, and changes that need action when updating (or break compatibility) the first one.

## 1.0.0 (2026-10-27)

First public release.

- Outliner with markdown: nested, foldable and movable bullets, tasks, headings, quotes, code and highlights.
- Links and tags, linked references with a filter, unlinked references.
- Daily notes, sidebar, rename and merge, attributes and templates, graph of all pages, search.
- Export and import of all pages as markdown files.
- End-to-end encryption in the browser (PBKDF2, HKDF, AES-256-GCM) with a recovery key.
- Installation on shared webhosting with PHP 8.2 or newer, or with Docker behind Caddy.
